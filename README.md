# TechNova — Página web

## Archivos
- `index.html`: estructura y contenido de la página.
- `styles.css`: colores, tipografía, componentes visuales y adaptación responsiva.
- `assets/`: carpeta para imágenes o recursos que quieras agregar después. La ilustración actual está construida con CSS, por lo que no requiere imágenes externas.

## Cómo abrir en Visual Studio Code
1. Descomprime `technova_web.zip`.
2. Abre Visual Studio Code.
3. Selecciona **Archivo > Abrir carpeta...** y elige `technova_web`.
4. Abre `index.html`.
5. Para verlo en el navegador, puedes abrir el archivo directamente o instalar la extensión **Live Server** y pulsar **Go Live**.
6. Se necesita conexión a internet para cargar Bootstrap y Bootstrap Icons desde sus CDN.

## Personalización rápida
- Cambia el nombre, textos y datos de contacto directamente en `index.html`.
- Cambia los colores principales al inicio de `styles.css`, dentro de `:root`.
- Ajusta espacios, tamaños y tarjetas en las reglas CSS correspondientes.
- Las ilustraciones de producto y del hero están hechas con CSS. Puedes sustituirlas por imágenes propias dentro de `assets/` usando etiquetas `<img>`.

## Importante
La página es una plantilla frontend estática. El formulario no envía información ni almacena solicitudes: para hacerlo necesitarás un backend o un servicio de formularios. Los teléfonos, correo y enlaces sociales son datos de ejemplo y deben sustituirse por los reales.
